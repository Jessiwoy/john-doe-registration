# John Doe Registration

Aplicação full stack para cadastro único de clientes, desenvolvida em React + TypeScript, NestJS + TypeScript e PostgreSQL.

Este repositório será evoluído incrementalmente seguindo Git Flow e Conventional Commits.

## Estrutura

```text
john-doe-registration/
├── backend/
├── frontend/

└── README.md
```
